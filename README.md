# Proyecto Lourdes Martínez — Century 21 Grupo Mormos

Estrategia de marketing inmobiliario y sitio web para **Lourdes Martínez**, Asesora Inmobiliaria Certificada de Century 21 Grupo Mormos.

## Objetivo del proyecto

Resolver el problema detectado de enero a julio: **cero cierres** por dos causas combinadas:

1. **Alcance (top-of-funnel):** a veces no llegaban mensajes → no se estaba llegando a suficiente público, ni al correcto.
2. **Conversión (bottom-of-funnel):** cuando llegaban mensajes, no eran de intención de compra → mala segmentación y falta de calificación/seguimiento.

La estrategia ataca **ambas puntas del embudo** y es **iterativa**: medimos, aprendemos y refinamos con métricas.

## Estructura de esta rama (`estrategia-lourdes`)

```
.
├── entregables-lourdes/     → Documentos para compartir con Lourdes (la clienta)
│   ├── 01-estrategia-integral.md

│   └── 03-calendario-contenido.md
└── interno/                 → Documentos de trabajo internos (equipo / Antonio)
    ├── 01-perfil-audiencia-icp.md
```

- **`entregables-lourdes/`**: material listo para presentar/entregar a la clienta.
- **`interno/`**: análisis, segmentación, métricas y planeación para uso del equipo.
